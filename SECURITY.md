# Security policy

Please do not open a public issue for a security problem. Report it privately to
**qooqapp1010@gmail.com**, or with GitHub's **Report a vulnerability** button under this
repository's *Security* tab.

The full policy, shared with the daemons, is in
[qooqapp/qooq's SECURITY.md](https://github.com/qooqapp/qooq/blob/main/SECURITY.md).
